# Jellyfin

Or JellyBox, because it runs in a box.

[JellyFin Docs](https://jellyfin.org/docs/)

- IPv4, IPv6, SDWAN enabled.
- 4 vCPU Cores
- 8 GB Memory
- 256 GB SSD
- Hardware Transcoding Enabled (QSV)

## Monitoring

Basic TCP-port monitoring into UptimDawg.

### Limitations

- No 4K content
- Not Publicly Available. Must use Tailscale.

### Family Setup Process

- Create Tailscale Account
- Request Access
- Accept TailNet Share Invite
- Get Welcome Email
- Login to Jellyfin
